# Metaspace Interiors

A website demo for an interior design studio, deployed with GitHub Pages.

**Live demo:** https://dhairya160708.github.io/metaspace-interiors/

## About this repository

This repository holds the production build of the site on the `gh-pages` branch, which GitHub Pages serves directly. It contains the compiled `index.html` and static assets.

## View locally

Clone the repo and open `index.html` in your browser.

> This is a demo project built for portfolio purposes.
